# Radar Viral

Painel pessoal que mostra os posts em alta no Instagram nos temas escolhidos (saúde mental e neurodesenvolvimento; finanças e vendas), usando a Instagram Graph API oficial.

- Abra a página publicada pelo GitHub Pages.
- Em **Configurar**, cole a chave de acesso e clique em **Conectar**. A chave fica salva só no seu navegador e nunca vai para este repositório.
- Clique em **Atualizar** para buscar os posts.
